# Square Social Platform

An Android social media application that allows users to register, log in, create posts, and browse a social feed with comments and profiles.

## Features

- User registration and login
- Create and view posts
- Social feed with comments
- User profiles

## Tech Stack

- **Languages:** Kotlin, Java
- **Platform:** Android
- **Database:** SQLite (via DatabaseHelper)

## Getting Started

1. Clone the repository
2. Open the project in Android Studio
3. Build and run on the Android emulator. API 31 or later.
